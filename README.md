# Health Insurance Policy and Claims Management System

## Project Overview

This project focuses on the design and implementation of a Database
Management System for managing health insurance policies and claims.

The system organizes insurance-related information and supports
database operations for policy management, claim processing,
reporting, and testing.

## Objectives

- Design a structured relational database.
- Organize health insurance policy and claims information.
- Implement SQL queries for retrieving and analyzing data.
- Apply claim decision logic.
- Test database operations and validate results.
- Provide a user interface for interacting with the system.

## Technologies Used

- SQL
- Relational Database Management System
- HTML, CSS, and JavaScript for the user interface, if applicable

## Repository Structure

- `Source-Code/ISIS-Insurance-Management-UI/` — User interface source code.
- `01_database_structure.sql` — Database structure and schema.
- `02_sample_data.sql` — Sample database records.
- `03_queries_and_reports.sql` — SQL queries and reports.
- `04_claim_decision_logic.sql` — Claim decision logic.
- `05_database_testing.sql` — Database testing queries.
- `DBMS Report Final.docx` — Final project report.

## Getting Started

1. Clone or download this repository.
2. Open your database management software.
3. Create a database for the project.
4. Execute the SQL files in the following order:

   1. `01_database_structure.sql`
   2. `02_sample_data.sql`
   3. `03_queries_and_reports.sql`
   4. `04_claim_decision_logic.sql`
   5. `05_database_testing.sql`

5. Review the query results to verify the database operations.

The exact setup steps may vary depending on the database software
used by your project.
